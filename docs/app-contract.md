# Контракт приложения CoShip 0.1

Поддерживаются HTML/CSS/JavaScript, локальные ES-модули и TypeScript, плюс необязательные серверные JS/TS-функции. Любой AI-инструмент может подготовить эти файлы и вызвать CLI или MCP. Произвольные серверы, Dockerfile и установка npm-зависимостей на платформе не поддерживаются. Зависимости соберите локально в браузерный bundle.

## Манифест

В корне проекта нужен `coship.json`:

```json
{
  "manifestVersion": "1",
  "name": "Задачи отдела",
  "runtime": "coship-js-v1",
  "entry": "index.html",
  "functions": {},
  "data": {
    "profile": "app-shared",
    "collections": {
      "items": {
        "schema": {
          "type": "object",
          "properties": { "title": { "type": "string", "maxLength": 200 } },
          "required": ["title"],
          "additionalProperties": false
        },
        "operations": ["list", "get", "insert", "update", "delete"]
      }
    }
  },
  "connectors": []
}
```

Профиль `app-shared` означает одну общую базу приложения. Пользователь с `viewer` читает записи, с `user` — также изменяет; перечень `operations` может только сузить права. Владелец управляет приложением, но его доступ к записям также проверяется отдельным grant. При создании владелец получает такой grant автоматически.

Нет полей для отключения входа, публичного доступа, SQL, секретов или произвольной сети. JSON Schema встроенная, без внешних ссылок и регулярных выражений. Изменение схемы допускается только совместимое: например, добавить необязательное поле. Удаление коллекции, сужение схемы или миграция данных требуют отдельного механизма, которого в MVP нет.

## Браузерный SDK

Платформа вставляет SDK до кода приложения:

```js
const items = window.coship.data.collection('items');
const page = await items.list({ limit: 50 });
const created = await items.insert({ title: 'Проверить договор' });
const updated = await items.update(created.id, { title: 'Готово' }, created.revision);
await items.delete(updated.id, updated.revision);
```

`list` возвращает `{items, next_cursor}`, следующая страница — `list({cursor: next_cursor})`. `get(id)` возвращает запись. Запись имеет `id`, `payload`, `revision`, `created_at`, `updated_at`. У `insert` второй аргумент — необязательный UUID идемпотентности; при повторе запроса используйте тот же UUID. Устаревшая `revision` даёт конфликт. Обновление заменяет весь `payload`.

Код не получает сессию платформы. Вызовы проходят через доверенную оболочку и серверную проверку текущих прав. Iframe имеет непрозрачный origin; CSP блокирует сетевые подключения, отправку форм и внешние ресурсы. Встраивайте картинки и шрифты как data URL. Не включайте в исходники персональные данные: копия приложения копирует исходники, включая любые вручную зашитые строки.

## Серверная функция

Требует подключённого Linux/gVisor-runner. В манифесте: `"functions": {"summary": "functions/summary.ts"}`.

```ts
export default async function summary(input: unknown, ctx: any) {
  const { items } = await ctx.data.collection('items').list({ limit: 100 });
  return { countOnPage: items.length };
}
```

Вызов: `await window.coship.functions.invoke('summary', {})`. `ctx.data` использует тот же контракт и права текущего зрителя. Функция — самостоятельный модуль; внешние зависимости нужно заранее собрать в один файл. Неизолированного запасного режима нет. Контейнер не получает сеть, токены, ключи БД или секреты платформы.

## Лимиты и публикация

До 100 файлов / 2 MiB пакета; отдельная запись до 64 KiB; до 10 000 записей на приложение, 100 приложений и 100 релизов на приложение. Страница данных до 100 записей. Runner: 10 секунд, 256 MiB, 0,5 CPU, 64 процесса, 1 MiB вывода и 100 обращений к данным на вызов. Эти квоты MVP фиксированы в коде.

`coship inspect` проверяет пакет без запуска скриптов проекта. `publish` возвращает deployment со статусом `active` или `failed`. Ошибка проверки не меняет активный релиз. Обновление привязано к известному `expected_release_id`. Откат меняет только активный код и допускается при одинаковой схеме данных; записи и права не откатываются.

MCP читает только указанную папку `--root`; симлинки и выход за корень запрещены. CLI-токен действует 24 часа и имеет ограниченную область действий. Браузерная сессия действует 12 часов; отключение сотрудника отзывает обе.
