# CoShip

**Создать с любым AI-инструментом. Опубликовать и поделиться как документом.**

CoShip — корпоративная платформа для небольших внутренних приложений. Пользователь приносит код из своего AI-инструмента, публикует его и выбирает, кому открыть доступ. Платформа управляет входом, данными, секретами, исполнением кода и жизненным циклом приложения.

[Архитектура MVP](docs/architecture.md) описывает компоненты, границы доверия, модель «Поделиться», контракты CLI/MCP, хранение данных, локальное размещение и критерии проверки.

Ключевые решения:

- Один Publish API для CLI и MCP; JS/TS-функции и статический интерфейс как первый контракт приложения.
- Данные доступны только через платформенный Data Broker, с проверкой прав текущего пользователя.
- Изолированное исполнение функций без ключей БД, корпоративных токенов и прямого выхода в сеть.
- «Поделиться» управляет собственной базой приложения; права корпоративного источника остаются дополнительным ограничением.
- Код, данные и права версионируются и управляются отдельно. Копия приложения получает пустую базу.
- Один переносимый комплект для локального облака или инфраструктуры клиента.

В репозитории находится проект архитектуры, не реализация работающей платформы. Календарный план не включён.
